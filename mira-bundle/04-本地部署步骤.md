## 一、如何从服务器下载压缩包到你的电脑

在你的**本地电脑终端（Windows PowerShell / macOS Terminal）**执行：

```powershell
scp lucas@10.113.17.65:/tmp/mira-competition-20261125.zip .\
```

> 也可以在 Cursor 中打开 `/tmp/mira-competition-20261125.zip` 或通过 SFTP 工具（WinSCP / MobaXterm / FinalShell）直接从 `/tmp/mira-competition-20261125.zip` 下载到本地。

下载后解压到任意不含中文和空格的路径，例如：
- Windows：`D:\mira-competition\`
- macOS / Linux：`~/mira-competition/`

解压后目录结构如下：
```text

├── 01-报名提案填写稿.md
```

## 二、前置环境要求

在本地电脑安装以下基础软件：

1. **Python 3.10+**（强烈推荐 **Python 3.12**）
   - 检查命令：`python --version`（macOS/Linux 为 `python3 --version`）
2. **Node.js 20+**（自带 npm）
   - 检查命令：`node -v` 和 `npm -v`
3. **Git**
   - 检查命令：`git --version`
4. **Docker Desktop**（强烈推荐，用于一键启动 PostgreSQL 16）
   - 若电脑不方便装 Docker，可直接用后文“方案 B：SQLite 零 Docker 备选”运行。
5. **可选：本地 LLM（Ollama）**
   - 如需离线运行 AI 助手，可安装 [Ollama](https://ollama.com/) 并拉取模型：
     ```bash
     ollama pull qwen2.5:14b
     ```
     （显存/内存较小时可用 `qwen2.5:7b`）

## 三、一步步部署 Mira 主系统

以下以进入 `mira-bundle/MET_Jira` 目录为起点。

### 第 1 步：初始化本地 Git 仓库（重要，方便赛事期间追踪 Qoder 改动）

```bash
cd mira-bundle/MET_Jira
git init
git add .
git commit -m "chore: pre-competition baseline snapshot"
```

### 第 2 步：创建本地配置文件 `.env`

**Windows PowerShell：**
```powershell
Copy-Item .env.local.example .env
```

**macOS / Linux：**
```bash
cp .env.local.example .env
```

用编辑器打开 `.env`，确认以下关键项：
- `METJIRA_SECRET`：改成任意 32 位以上随机字符串。
- `METJIRA_AUTH_MODE=local`：纯本地账号模式，无需企业 AD/LDAP。
- `METJIRA_SEED_SAMPLE_PROJECT=true`：首次初始化自动创建示例项目 `ELEC`。
- `METJIRA_LLM_ENABLED`：如果暂时还没配大模型，可先改为 `false` 把系统跑起来，接好大模型后再改回 `true`。

### 第 3 步：启动数据库（二选一）

#### 方案 A：Docker 启动 PostgreSQL 16（推荐，功能 100% 完整）

在 `MET_Jira` 根目录运行：
```bash
docker compose up -d
```

等待 5—10 秒检查容器健康状态：
```bash
docker compose ps
```
看到 `met-jira-postgres` 状态为 `Up (healthy)`，端口 `127.0.0.1:5433->5432/tcp` 即成功。

#### 方案 B：零 Docker 快速启动（SQLite 备选）

如果电脑没有 Docker，打开 `.env`，注释掉 PostgreSQL 两行，改为：
```env
# METJIRA_DATABASE_URL=postgresql+psycopg://met_jira:met_jira_dev@127.0.0.1:5433/met_jira
# METJIRA_DB_PASSWORD=met_jira_dev
METJIRA_DATABASE_URL=sqlite:///./data/mira_local.db
```
> 注：SQLite 可正常运行绝大部分功能与全部单测；仅 PostgreSQL 专属的 `pg_trgm` 相似度查重与数据库级 advisory lock 需 PostgreSQL 16。正式比赛演示建议优先使用方案 A。

### 第 4 步：安装 Python 虚拟环境与后端依赖

**Windows PowerShell：**
```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
pip install -e ".[dev]"
```
> 若 PowerShell 提示禁止运行脚本，先执行一次：`Set-ExecutionPolicy -Scope CurrentUser RemoteSigned`

**macOS / Linux：**
```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
pip install -e ".[dev]"
```

### 第 5 步：初始化数据库（Alembic 迁移 + 种子数据）

确保虚拟环境已激活，执行：
```bash
python -m backend.ops bootstrap
```

这一步会自动完成：
1. 创建 `data/`、`data/attachments/`、`data/imports/` 目录；
2. 执行全部 Alembic 迁移（表结构初始化）；
3. 写入内置部门模板（电气/机械/生产/AI）；
4. 创建默认本地管理员账号：`admin` / `MetJira123!`；
5. 首次自动创建示例项目 `ELEC`。

### 第 6 步：安装前端依赖并构建

```bash
cd web
npm ci
npm run build
cd ..
```

构建成功后会生成 `web/dist/`，后端会自动托管该静态产物。

### 第 7 步：启动 Mira 服务

#### 模式 1：单进程一体化运行（推荐演示用）
```bash
python -m uvicorn backend.main:app --host 127.0.0.1 --port 8800
```
- 浏览器访问：`http://127.0.0.1:8800`
- 健康检查：`http://127.0.0.1:8800/api/health`（返回 `{"status":"ok",...}`）
- 登录账号：`admin` / `MetJira123!`

#### 模式 2：前后端热重载开发模式（参赛编码时使用）
- **终端 1（后端热重载）**：
  ```bash
  python -m uvicorn backend.main:app --reload --host 127.0.0.1 --port 8800
  ```
- **终端 2（前端 Vite 热更新）**：
  ```bash
  cd web
  npm run dev
  ```
- 浏览器访问：`http://127.0.0.1:5180`（Vite 自动将 `/api` 代理至 `127.0.0.1:8800`）。

## 四、大模型（LLM）接入指南

Mira 通过 `backend/services/llm.py` 调用 OpenAI 兼容接口（`{METJIRA_LLM_BASE_URL}/chat/completions`）。

### 方式 1：本地 Ollama / LM Studio / vLLM（开箱即用，无需改代码）
1. 启动本地 Ollama（默认监听 `127.0.0.1:11434`）。
2. 在 `.env` 中配置：
   ```env
   METJIRA_LLM_ENABLED=true
   METJIRA_LLM_BASE_URL=http://127.0.0.1:11434/v1
   METJIRA_LLM_MODEL=qwen2.5:14b
   METJIRA_LLM_TIMEOUT=90
   ```
3. 重启后端即可在右侧面板或建单“AI 起草”中测试。

### 方式 2：公网需要 API Key 的云端模型（DeepSeek / 通义千问 / OpenAI 等）
> **重要提示**：原版 `backend/services/llm.py` 对接内网免鉴权网关，因此未携带 `Authorization: Bearer` 请求头。

如果你要接云端模型，有两种办法：
- **办法 A（推荐，直接让 Qoder 改 5 行代码）**：
  1. 在 `backend/config.py` 读取 `METJIRA_LLM_API_KEY`；
  2. 在 `backend/services/llm.py` 的 `httpx.post` 与 `httpx.stream` 请求中，当 `api_key` 非空时传入 `headers={"Authorization": f"Bearer {api_key}"}`；
  3. 在 `.env` 中配置 `METJIRA_LLM_BASE_URL`、`METJIRA_LLM_MODEL` 和 `METJIRA_LLM_API_KEY`。
- **办法 B（免改代码）**：本机跑一个轻量代理（如 `litellm --model deepseek/deepseek-chat --port 4000`），然后让 `METJIRA_LLM_BASE_URL=http://127.0.0.1:4000/v1`。

## 六、常见问题排错（FAQ）

1. **`docker compose up -d` 报错 5433 端口被占用**
   - 修改 `compose.yaml` 中的 `"127.0.0.1:5433:5432"` 为 `"127.0.0.1:5439:5432"`，并同步把 `.env` 中 `METJIRA_DATABASE_URL` 的端口改为 `5439`。
2. **Windows 上执行 `pip install -e ".[dev]"` 报 psycopg 编译错误**
   - `pyproject.toml` 已使用 `psycopg[binary]>=3.2` 预编译轮子，一般无需 C 编译器；若仍报错，请确认 Python 版本为 3.11 或 3.12（64 位）并先执行 `python -m pip install --upgrade pip`。
3. **打开 `http://127.0.0.1:8800` 显示找不到前端页面**
   - 说明尚未执行 `cd web && npm run build` 生成 `web/dist`；执行构建后刷新即可。
4. **修改了 `.env` 但没生效**
   - `backend/config.py` 在进程启动时读取 `.env`，修改后需 `Ctrl+C` 停止并重新启动 `uvicorn`。
5. **想彻底重置本地数据库重新开始**
   - PostgreSQL：`docker compose down -v && docker compose up -d && python -m backend.ops bootstrap`
   - SQLite：删除 `data/mira_local.db` 和 `data/.sample_project_seeded` 后重新执行 `python -m backend.ops bootstrap`
