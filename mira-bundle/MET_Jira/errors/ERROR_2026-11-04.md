# Error log — 2026-11-04

## A narrow board column clipped the card footer

- Symptom: On the board, a card such as PVDALPHA2-2 showed the key, the test result, and the date, then cut off the priority icon and the assignee avatar.
- Source: User report, with a screenshot of the 测试通过 column.
- Context: `web/src/styles.css` board column rules. Staging port 8810.
- Cause: Columns used a fixed minimum width and could shrink. The card footer stayed on one line, so the right-hand controls sat outside the column.
- Fix: Let each column grow to the width of its card content. The board scrolls sideways when the row is wider than the page. The footer no longer clips the key or the avatar.

## The workflow page jumped while AI checked the flow

- Symptom: Opening an AI fix or an optimization draft pushed the flowchart down. Updating wires also changed the canvas zoom.
- Source: User report on the staging workflow settings page.
- Context: `web/src/components/WorkflowAgentBar.tsx`, `web/src/components/WorkflowGraphEditor.tsx`. Staging port 8810.
- Cause: The check text, the suggestion list, and the draft mounted and unmounted, so the block above the canvas changed height at once. The graph replaced nodes without their measured size and fitted the view again on each update.
- Fix: Keep the header and the button widths stable. Grow and shrink the list and the draft with the content height. Fit the canvas once, and reuse the measured nodes after that.
